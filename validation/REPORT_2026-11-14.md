# EpochLab — real-data validation, 2026-11-14

Run on the team's Windows 11 machine through the local API (`POST /api/jobs`, `n_controls=2`, default `max_frames=80`, cutout 600″), SPHEREx DR1 spectral images from NASA/IPAC IRSA, Gaia DR3 / SIMBAD references. Every number below is copied from the job dossiers in `data/jobs/<job>/dossier.json`.

**Not covered by this run:** injection–recovery and `reproduce` (both are in `scripts/selftest_real.py --run`, which must be executed from a shell).

## What changed before this run

1. **FLAGS were not being read.** DR1 cutouts define the FLAGS bit planes as `MSKNnnnn = '<NAME>'`, `MSKMnnnn = 1<<n`; the parser only knew `MP_*`. Every frame of the earlier runs carried the warning *flags not interpreted*, so OVERFLOW / NONLINEAR / TRANSIENT / SUR_ERROR / BLOOM pixels were fitted as good data (up to 65 of the 121 stamp pixels on Barnard's Star). Fixed in `spherex_fits._parse_flag_bits`; artefact planes OUTLIER, STREAK, SNOWBALL, BLOOM, HALO added to the rejection list (SOURCE, GHOST*, CROSSTALK, FULLSAMPLE are kept on purpose).
2. **Variability verdict made robust** (rules only, measurements unchanged): a rejection of constant flux carried only by PSF-wing fluxes of a saturated core → `POSSIBLE (saturated core)`; carried by a single wavelength bin → `POSSIBLE (one λ bin)`; fewer than 3 repeat measurements → `INCONCLUSIVE`.
3. **Association gate (after this run, not yet applied to the WISE 0855 numbers below):** with catalogue PM + parallax the gate is max(2.5″, 4σ) instead of a fixed 6″.

## Reading

* **Proper motion.** Barnard's Star now agrees with Gaia DR3 to 0.2σ / 0.5σ (it was 4.5σ off), ε Indi B to 1.1σ / 0.3σ with ±67 mas/yr errors over 1.44 yr. With 6.15″ pixels and ≤ 1.5 yr of SPHEREx data the 1σ precision is 70–200 mas/yr for well-detected sources: enough to verify fast movers, not slow ones.
* **Field-star controls** pass on every field (0 % of control stars beyond 3σ; z scatter 0.57–0.91, i.e. errors are conservative rather than underestimated).
* **WISE 0855.** Its own detections are only at 4.22–4.55 µm (4 exposures, S/N ≈ 5), as expected for a Y dwarf. Eight detections at 0.86–2.54 µm sit 3.5–4.8″ away at a common offset: a neighbouring source that passed the old 6″ gate. The new gate removes them; this target must be re-run before quoting its motion.
* **RW Aur** is strongly variable (χ² 1045 / 18, max/min 3.8 within single wavelength bins) and shows a wavelength-dependent photocentre (r = +0.67): consistent with an unresolved, variable binary (RW Aur A+B, 1.4″). Its 2.7σ RA motion offset is likely the same blend effect.
* **R Dra** (Mira) saturates SPHEREx in almost every exposure (median 112 of 121 stamp pixels flagged): 6 usable measurements, variability `INCONCLUSIVE`. The earlier 'NO EVIDENCE' came from fitting saturated pixels.
* **Barnard's Star 'variability'** is now `POSSIBLE (saturated core)`: every flux is from PSF wings. Not a variability claim.
